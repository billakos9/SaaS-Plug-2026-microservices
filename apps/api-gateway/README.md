# API Gateway

Nginx gateway and canonical public entrypoint for saasPlug.

## Responsibilities

- Exposes the public app/API port.
- Proxies `/api/*` paths to internal services.
- For VM/demo mode, serves the built React SPA from `/`.
- Keeps direct service/database ports closed in production-like mode.
- Applies API rate limiting.

## Public Routing

Examples:

```text
/api/auth/*          -> auth-service:3000/auth/*
/api/users/me       -> user-service:3000/user/me
/api/chargers/*     -> charger-service:3000/charger/*
/api/reservations/* -> reservation-service:3000/reservation/*
/api/admin/*        -> admin-service:3000/admin/*
/api/analytics/*    -> analytics-service:3000/analytics/*
/api/billing/*      -> billing-service:3000/billing/invoices/*
```

Internal service health endpoints are intentionally not exposed directly through
the gateway. Admin users should use:

```text
GET /api/admin/system-health
```

## Files

```text
nginx.conf           Base API gateway config
rate-limit.conf      Nginx rate-limit zones
docker/Dockerfile    Gateway container image
nginx.vm.conf        Generated by scripts/setup-vm.py, ignored by git
```

## Ports

Default compose mode exposes only the gateway:

```yaml
${PUBLIC_HTTP_PORT:-80}:80
```

For Team 09 VM mode:

```bash
PUBLIC_HTTP_PORT=3309 docker compose up -d --build
```

## Frontend Serving

`scripts/setup-vm.py` builds `apps/web-app` and generates `nginx.vm.conf`, which
adds:

```nginx
location / {
    root /usr/share/nginx/html;
    try_files $uri $uri/ /index.html;
}
```

The generated `docker-compose.override.yml` mounts:

```text
apps/web-app/dist -> /usr/share/nginx/html
apps/api-gateway/nginx.vm.conf -> /etc/nginx/conf.d/default.conf
```
